# Справочник пользователей (Практическое задание 3Б)

Небольшое одностраничное приложение на чистом HTML/CSS/JS для загрузки
пользователей и их публикаций с публичного REST API
`https://jsonplaceholder.typicode.com`.

## Демо
🔗 **GitHub Pages:** https://attbjjb.github.io/task3b/

## Файлы
- `index.html` — разметка интерфейса
- `style.css` — оформление
- `app.js` — логика (fetch, async/await, DOM, события)
- `README.md` — этот файл

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в любом современном браузере (Chrome, Firefox, Edge).
   Достаточно двойного клика — сборка и сервер не требуются, так как используется
   публичный API по HTTPS.
3. Или воспользуйтесь онлайн-версией: https://attbjjb.github.io/task3b/

## Как пользоваться
1. Нажмите **«Загрузить пользователей»** — появятся 10 карточек с именем,
   email и городом.
2. Введите имя в поле **«Поиск по имени»** — список фильтруется на клиенте
   без нового HTTP-запроса (регистр не важен).
3. Нажмите **«Показать публикации»** у любого пользователя — в отдельной
   области появятся заголовки и тексты первых трёх его публикаций.
4. Во время запросов отображается «Загрузка...», кнопка загрузки блокируется
   и затем снова активируется.

## Результаты проверок
- ✅ «Загрузить пользователей» → 10 пользователей (имя, email, город).
- ✅ Ввод «Leanne» → остаётся только Leanne Graham.
- ✅ Ввод неизвестного имени → «Пользователи не найдены».
- ✅ «Показать публикации» → 3 публикации выбранного пользователя
      (заголовок + текст) в отдельной области.
- ✅ Подмена `/users` на `/userz` → сообщение об ошибке (HTTP 404),
      кнопка снова активна, после возврата правильного адреса повторный
      запрос работает.
- ✅ CSS-оформление присутствует: карточки, кнопки, цвета статусов.

## Технологии
HTML5, CSS3, Vanilla JavaScript (fetch, async/await, try/catch/finally,
addEventListener, createElement, textContent). Без фреймворков,
localStorage и серверной части.
